Define what object oriented programming is
Object-oriented programming means organizing software design around objects that bundle data and behavior together, rather than around logic and functions alone.
How many pillars are there in OOP
There are 4 pillars, they are Encapsulation, Abstraction, Inheritance, and Polymorphism.
What are the main parts of a class?
The main parts of a class are its Attributes (data variables) and methods (functions).
How do we create a class in python?
You make a class in python by using the class keyword followed by the class name and a colon. Then you define it's attributes and methods.
What are the differences between a class and a object
A class is a blueprint or template that defines the structure and behavior, while an object is a specific instance created from that class with actual data.
